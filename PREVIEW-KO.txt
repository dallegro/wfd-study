wfd. v1.5.0 — 사용자 흐름 개선 출시 후보

Mac 실행: 압축 해제 후 터미널에서
cd ~/Downloads/wfd-study-v1.5.0-clean && python3 -E tests/http_server.py 8011
Chrome: http://localhost:8011

이전 버전의 공개 사이트와 localhost 포트는 저장 공간이 서로 다릅니다.
기존 JSON 백업은 복습 > 기록 관리 > 기록 불러오기에서 복원합니다.
불러오기는 현재 기록을 대체하므로 먼저 필요한 기록을 내보내세요.

변경 사항: 복습 기본 탭에서만 전체 통계 표시, 탭별 주요 행동 하나, 문장별 기록 및 단어 목록 접기·더 보기, 취약 단어 누적 오류 목록, 복습 진행률, 간결한 채점 피드백, 실전 안내 및 결과 요약, 문장별 결과는 한 번에 하나만 펼치기. 기존 데이터 모델, 음원 및 재생 엔진 유지.

추가 개선: 개별 연습 진행률 숨김, 여러 문장 연습의 실제 순서 표시, 단어 위치와 이전 채점 정보 숨김, 채점과 보조 행동 정렬, 기록 저장 안내 이동, 실전 시작 화면 중복 제목 제거.

추가 개선: 복습 예정·오답만 연습, 학습 이력·취약 단어는 읽기 전용, 복습 버튼 용어 통일, 구분선 정리.

검증 범위: Node 핵심 테스트, Chromium 메모리 기반 UI 및 모의 실전 재생 테스트. 실제 HTTP/서비스 워커, 모바일 오디오, 원어민 다국어 검수는 별도 확인이 필요합니다. GitHub에 반영하지 않았습니다.
